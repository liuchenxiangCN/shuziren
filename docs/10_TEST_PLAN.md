# 测试计划

## 测试原则

- 每个阶段都有独立验收。
- Mock 阶段不依赖外部平台。
- 真实集成阶段保留 Mock 回退路径。
- POC 前必须形成可重复演示脚本和测试问题清单。

## POC 准备验收

- 至少 10 个稳定演示问题。
- 至少 5 份测试知识库文档。
- 至少 3 位测试领导资料。
- 至少 3 个大屏动作。
- 响应时间能记录 ASR / Dora / TTS / 总耗时。
- 失败时不出现系统报错裸露。
- 不执行模型生成 JavaScript。
