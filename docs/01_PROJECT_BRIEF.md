# 项目简介

## 背景

客户为中天证券, 现已有 Dora 平台和 FVS 大屏看板。本阶段不重新开发大屏内容, 而是在本地 Windows + Docker 环境中补齐数字人交互相关组件, 跑通可演示、可复用、可逐步替换真实服务的 POC 主链路。

## 建设目标

本阶段目标不是一次性完成生产级交付, 而是先跑通完整链路:

```text
语音唤醒
-> 语音识别 ASR
-> 文本问题
-> Dora Agent
-> Dora 问数 / RAGFlow 知识库 / 大屏控制动作
-> 回复文本 / 图文结果 / screen_action
-> TTS 语音合成
-> 前端播报 + 动效 + 字幕 + FVS 控制
```

## 核心场景

- 领导身份识别与新闻知识库问答。
- 党建资料文档问答。
- 党建大屏数据问数与总结分析。
- 语音控制大屏切换。

## 本阶段非目标

- 不做 2D / 3D 数字人形象。
- 不做声纹识别。
- 不做人脸识别。
- 不做系统级常驻唤醒。
- 不做 FVS 看板重新开发。
- 不做真实生产知识库调优。
- 不做证券客户正式合规评审。
- 不承诺复杂问数和归因分析效果。
- 不让大模型直接生成并执行任意 JavaScript。
- 不把本地开发方案直接作为最终生产部署方案。

## 领导身份识别边界

本项目中的“领导身份识别”不是严格身份认证, 只做文本层面的信息匹配:

```text
用户自报领导姓名 / 职务
-> 系统识别文本中的姓名或职务
-> 在测试领导资料库中匹配
-> 若唯一命中, 生成欢迎语或相关新闻摘要
-> 若同名、同姓、同职务, 进行多轮确认
```

## 可复用目标

本工程不是只服务中天证券的一次性交付, 而应沉淀为客户 POC 模板:

- 核心代码通用。
- 客户配置可替换。
- Dora Prompt 可替换。
- 大屏动作白名单可替换。
- 知识库样例可替换。
- 演示脚本可替换。
