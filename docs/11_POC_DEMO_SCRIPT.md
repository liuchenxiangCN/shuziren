# POC 演示脚本

> Lifecycle: `CUSTOMER_SPECIFIC` / `ARCHIVED_POC_SNAPSHOT`。本文是中天证券党建 POC 演示证据，不是标准产品默认场景或当前开发任务。

本文档用于沉淀客户演示流程。V0.9 已补齐预检、启停、日志导出、演示稳态和固定 smoke 脚本, 当前脚本可用于 POC 稳定版复演。截图和现场实测耗时可在正式验收报告中继续补充。

## 演示目标

在本地环境中展示数字人围绕党建大屏完成:

- 唤醒。
- 领导欢迎。
- 党建知识问答。
- 党建数据问数。
- 大屏页面切换。
- TTS 播报和状态动效。

## 演示前检查

- 运行 `scripts\check-poc.ps1 -RequireServices`。
- 必要时运行 `scripts\smoke-demo.ps1`。
- 前端页面可访问。
- 后端健康检查正常。
- Mock 或真实 Dora 配置明确; 问数问题由本地 Excel Adapter 优先承接。
- FVS iframe 或 Mock 大屏可见。
- 麦克风权限可用。
- 音箱或系统声音可用。
- 日志目录可写。
- `docs/demo_data/ask_metrics/` 三份 Excel 存在, Docker 中 `/app/docs/demo_data` 为只读挂载。

## 推荐演示顺序

### 1. 开场

说明:

```text
这是中天证券党建大屏语音交互 POC。本阶段重点验证完整链路和交互方式, 不做 2D/3D 人物形象。
```

### 2. 唤醒

用户:

```text
小天小天
```

期望:

- 语音球进入唤醒状态。
- 字幕显示进入对话。

### 3. 领导欢迎

用户:

```text
我是张书记
```

期望:

- 返回欢迎语。
- 展示领导关注方向。
- 播报欢迎话术。

### 4. 知识库问答

用户:

```text
入党流程是什么？
```

期望:

- 基于知识库返回简短回答。
- 屏幕展示摘要和要点。
- TTS 播报。

### 5. 党建问数

用户:

```text
当前党员学习完成率是多少？
```

期望:

- 返回测试指标。
- 展示摘要、要点和数据来源。
- 播报总结。

### 6. 大屏控制

用户:

```text
请切换到成品库存页面
```

期望:

- Dora 输出 `SWITCH_TAB_ORG`。
- Gateway 校验白名单。
- FVS 或 Mock 大屏切换。
- 播报“已为您切换到成品库存页面”。

### 7. 异常兜底

用户:

```text
打开一个不存在的页面
```

期望:

- 不执行动作。
- 播报“当前大屏暂不支持这个切换动作”。
