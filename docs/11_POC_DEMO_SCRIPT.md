# POC 演示脚本

本文档用于沉淀客户演示流程。当前为初始草案, 后续联调后需要补充真实截图、实际耗时和稳定问题。

## 演示目标

在本地环境中展示数字人围绕党建大屏完成:

- 唤醒。
- 领导欢迎。
- 党建知识问答。
- 党建数据问数。
- 大屏页面切换。
- TTS 播报和状态动效。

## 演示前检查

- 前端页面可访问。
- 后端健康检查正常。
- Mock 或真实 Dora 配置明确。
- FVS iframe 或 Mock 大屏可见。
- 麦克风权限可用。
- 音箱或系统声音可用。
- 日志目录可写。

## 推荐演示顺序

### 1. 开场

说明:

```text
这是中天证券党建大屏语音交互 POC。本阶段重点验证完整链路和交互方式, 不做 2D/3D 人物形象。
```

### 2. 唤醒

用户:

```text
小天小天
```

期望:

- 语音球进入唤醒状态。
- 字幕显示进入对话。

### 3. 领导欢迎

用户:

```text
我是张书记
```

期望:

- 返回欢迎语。
- 展示领导关注方向。
- 播报欢迎话术。

### 4. 知识库问答

用户:

```text
入党流程是什么？
```

期望:

- 基于知识库返回简短回答。
- 屏幕展示摘要和要点。
- TTS 播报。

### 5. 党建问数

用户:

```text
当前党员学习完成率是多少？
```

期望:

- 返回测试指标。
- 可展示图文或 ECharts。
- 播报总结。

### 6. 大屏控制

用户:

```text
请切换到组织建设页面
```

期望:

- Dora 输出 `SWITCH_TAB_ORG`。
- Gateway 校验白名单。
- FVS 或 Mock 大屏切换。
- 播报“已为您切换到组织建设页面”。

### 7. 异常兜底

用户:

```text
打开一个不存在的页面
```

期望:

- 不执行动作。
- 播报“当前大屏暂不支持这个切换动作”。
