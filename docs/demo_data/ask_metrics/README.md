# 党建问数测试 Excel 数据

本目录存放 V0.5 / V0.6 问数功能测试用的脱敏演示 Excel 数据。所有人员、支部和业务数据均为样例, 不代表真实客户数据。

V0.7 已通过 Gateway 本地只读 Excel 问数 Adapter 接入这些文件。`/api/chat` 和 `/api/chat/stream` 在调用 Dora 前会优先匹配固定问数意图, 命中后直接返回带数据来源的 `answer`。

## 文件清单

| 文件 | 主题 | 主要用途 |
| --- | --- | --- |
| `zt_party_study_metrics_2026.xlsx` | 党员学习 | 测试党员总数、学习完成率、支部完成率、平均学习时长、测试成绩和心得提交情况 |
| `zt_party_org_life_metrics_2026.xlsx` | 组织生活与党建活动 | 测试组织生活完成率、主题党日次数、活动参会率、整改事项和闭环率 |
| `zt_party_development_metrics_2026.xlsx` | 党员发展流程 | 测试申请人、入党积极分子、发展对象、预备党员、本年转正、材料和政审状态 |

## 典型问数问题

- 当前党员学习完成率是多少?
- 本月有多少人完成学习?
- 哪个支部学习完成率最低?
- 本月主题党日开展了几次?
- 组织生活平均参会率是多少?
- 整改事项闭环率是多少?
- 当前入党积极分子有多少人?
- 发展对象有多少人? 分别在哪些支部?
- 本年转正党员有多少人?
- 哪些党员发展材料还待补充?
- 总结一下当前党建工作整体情况。

## 口径提示

- 党员学习表口径固定为 2026 年 6 月, 党员总数 128 人, 已完成学习 112 人, 完成率 87.5%。
- 组织生活表口径为 2026 年 1-6 月, 活动完成需实际开展且记录完整。
- 党员发展表以当前阶段统计流程人数, 阶段包括申请人、入党积极分子、发展对象、预备党员和正式党员。
