# 中天证券客户资料

## 客户名称

中天证券。

## 当前已知系统

- 已部署 Dora 平台。
- 已部署 FVS 大屏看板。
- 当前暂不重新开发大屏具体内容。
- 问数数据和知识库文档可先使用测试内容。

## POC 目标

- 本地 Windows + Docker 跑通数字人全链路。
- 能嵌入或联动 FVS 看板。
- 能通过语音唤醒进入对话。
- 能调用国产 ASR 和 TTS。
- 能调用 Dora Agent 获取问数、知识库问答和大屏控制结果。
- 能通过白名单动作控制大屏切换。
- 能记录会话日志、错误日志和关键链路耗时。

## 客户化边界

以下内容应作为客户配置或客户文档维护:

- FVS URL。
- 大屏页面 / Tab ID。
- 领导资料。
- 党建新闻资料。
- 党建制度文档。
- 演示问题。
- Dora Agent Prompt 细节。
- 问数指标和口径。
