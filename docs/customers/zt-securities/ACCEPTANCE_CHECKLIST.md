# 中天证券 POC 验收清单

## 本地开发验收

| 项目 | 标准 | 状态 |
| --- | --- | --- |
| Docker 启动 | `docker compose up -d` 后前后端可访问 | 待完成 |
| 前端页面 | 能展示 FVS iframe 或 Mock 大屏 | 待完成 |
| 语音唤醒 | 中文唤醒词可进入对话态 | 待完成 |
| ASR | 能将语音识别为中文文本 | 待完成 |
| Dora | 能调用 Dora Agent 并返回结果 | 待完成 |
| RAGFlow | 能基于测试文档回答问题 | 待完成 |
| 问数 | 能返回测试党建指标 | 待完成 |
| 大屏控制 | 能输出 action_id 并通过白名单执行 | 待完成 |
| TTS | 能播报回答 | 待完成 |
| 动效 | 语音球、字幕、声波状态可见 | 待完成 |
| 日志 | 能保存每轮对话和耗时 | 待完成 |
| Mock | Dora / ASR / TTS / FVS 均有 Mock 开关 | 待完成 |
| 错误处理 | 任一服务失败时有兜底话术 | 待完成 |
