## V0.7 说明

当前问数问题由 Gateway 本地 Excel Adapter 承接, 数据来自 `docs/demo_data/ask_metrics/` 下脱敏样例。正式客户数据源和口径确认后, 可替换为 Dora 问数、FineBI / FVS 数据源或数据库 Provider。
