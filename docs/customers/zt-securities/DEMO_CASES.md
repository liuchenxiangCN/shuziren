# 中天证券演示用例

## 领导欢迎

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| ZT-L-001 | 我是张书记 | 返回张书记欢迎语 |
| ZT-L-002 | 张书记最近调研了什么 | 返回近期动态 |
| ZT-L-003 | 我是李主任 | 返回李主任资料 |

## 知识库问答

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| ZT-K-001 | 入党流程是什么 | 返回流程摘要 |
| ZT-K-002 | 党员学习制度有哪些要求 | 返回制度要点 |
| ZT-K-003 | 党支部组织建设规范是什么 | 返回规范摘要 |

## 问数

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| ZT-D-001 | 当前党员学习完成率是多少 | 返回完成率 |
| ZT-D-002 | 本月有多少人完成学习 | 返回人数 |
| ZT-D-003 | 总结一下当前党建工作整体情况 | 返回总结 |

## 大屏控制

| 编号 | 输入 | 期望 |
| --- | --- | --- |
| ZT-S-001 | 切换到组织建设 | 执行 `SWITCH_TAB_ORG` |
| ZT-S-002 | 打开党员学习 | 执行 `SWITCH_TAB_STUDY` |
| ZT-S-003 | 返回首页 | 执行 `SWITCH_HOME` |
