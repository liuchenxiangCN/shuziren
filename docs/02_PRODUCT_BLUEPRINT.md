## 产品承诺

客户不需要重做 FVS 大屏，也不需要为每块大屏复制一套代码。实施人员在后台注册大屏、选择 FVS 模板、数字人和能力套餐，完成预览后即可按单屏或大屏组发布；运营和运维人员可以持续调整、监控和回滚。

产品的五个核心价值:

- 多屏可管: 一个客户标准部署内统一管理一个站点的多块大屏，Site 层级保留未来扩展。
- 形象可扩展: 首批预留 Renderer / AvatarPackage 接口；取得合法资产后，2D / 3D Adapter 可按版本预取、切换和回滚。
- 能力可配: Dora、知识库、LLM、ASR、TTS、问数和控屏按屏组合。
- 资产复用: FVS、FineReport 模板、数字人、音色、动作和能力配置跨屏复用。
- 交付可控: 连接测试、配置校验、版本发布、审计、监控、备份和升级形成闭环。

当前实现仍是单实例 POC 基线；完整目标态见 [17_STANDARD_PRODUCT_DESIGN.md](17_STANDARD_PRODUCT_DESIGN.md)。

## 两类核心体验

### 大屏前用户

```text
唤醒 / 点击
-> 语音或文本提问
-> 按当前大屏 CapabilityProfile 路由
-> FineReport 官方问数 / 数据库 / Excel / 知识库 / Dora
-> 展示并播报带来源的回答
-> 如需控屏，后端验证 action_id 后执行
```

系统应根据该块大屏的数字人、音色、权限和业务配置回答，不得串用其他大屏配置。

### 实施与运营人员

```text
使用默认站点
-> 注册大屏
-> 绑定 FVS
-> 选择数字人
-> 选择能力套餐
-> 测试连接
-> 预览
-> 灰度发布
-> 监控 / 回滚
```

高频配置使用预设和向导，供应商协议、超时、熔断等低频参数放入高级设置。

## 产品对象

| 对象 | 用户理解 |
| --- | --- |
| 站点 / 大屏组 / 大屏 | “这套配置要运行在哪里” |
| 数字人人设 | “它是谁、怎么说话、如何接待” |
| 渲染器与形象包 | “它长什么样，当前使用哪个版本”；V1 首批只有接口和默认无形象模式 |
| 能力套餐 | “它能否听、说、问数、查知识、控屏” |
| 连接 | “FineReport、Dora、RAGFlow、语音供应商怎么接” |
| 数据与知识 | “它能回答哪些业务数据和资料” |
| 动作包 | “它能安全控制哪些 FVS 页面或组件” |
| 发布版本 | “本次变更何时生效，如何回滚” |

## 核心业务流程

### 1. FineReport / FVS 问数

```text
问题
-> 问数意图
-> 当前大屏 Provider 顺序
-> 官方插件 / 只读数据库 / Excel
-> 统一结果
-> 来源、口径、参数、时间和权限说明
-> 展示 / 播报
```

官方插件是目标客户的首选一等 Provider，但只有在版本、接口、认证、权限和授权契约确认后才进入产品支持。权限拒绝不得通过更高权限备用数据源绕过。

### 2. 知识问答

```text
问题
-> 当前大屏知识策略
-> Dora -> RAGFlow 或 Gateway 直连检索
-> 来源约束回答
-> 无依据时安全 fallback
```

知识库和 LLM 可以分别关闭；无 LLM 时可使用受控模板或提取式回答。

### 3. 大屏控制

```text
语音 / 文本指令
-> 解析候选 action_id
-> 后端动作与参数白名单校验
-> 返回本次 authorized_action
-> FVS Adapter 执行
-> 记录结果并播报
```

模型不能生成任意 JavaScript 或 FVS 函数直接执行。

### 4. 数字人形象热切换

这是 Renderer Adapter 接入后的目标流程。当前首批产品只实现接口预留和测试 Renderer，不承诺真实 2D / 3D 格式。

```text
选择目标形象版本
-> 格式 / 安全 / 许可证 / 硬件校验
-> 大屏资源预取
-> 预览 / 灰度
-> 对话边界原子切换
-> 监控
-> 必要时回滚
```

形象包只包含受支持资产和 manifest，不包含任意可执行代码。

## 多屏运行原则

- 每个大屏设备使用独立注册凭据获取可信运行上下文。
- 每块大屏绑定不可变配置发布版本。
- 同一数字人、能力套餐或动作包可以跨屏复用。
- 发布可按单屏、大屏组或站点灰度。
- 大屏离线时继续使用最近一个已验证版本。
- 产品 V1 默认一块大屏同一时刻运行一个活动数字人。

## 后台管理平台

后台按工作任务组织为:

- 总览。
- 大屏管理。
- 数字人中心。
- FineReport / FVS。
- 能力与连接。
- 数据与知识。
- 交互体验。
- 发布中心。
- 运维中心。
- 安全与系统。

现有 `/ops` 的依赖、会话、错误和耗时能力继续保留，但作为“运维中心”的一部分，不再代表完整后台。

## 运行时状态机

| 状态 | 含义 | Renderer 表现要求 |
| --- | --- | --- |
| idle | 待机 | 待机动作或低功耗姿态 |
| wakeup | 已唤醒 | 确认动作 |
| listening | 收音 | 倾听动作与音量反馈 |
| recognizing | 识别 | 识别提示 |
| thinking | 路由与处理 | 思考动作 |
| replying | 展示回复 | 回复内容出现 |
| speaking | TTS 播报 | 口型与动作同步 |
| screening | 执行 FVS 动作 | 控屏状态反馈 |
| error | 安全兜底 | 简短错误提示后恢复 |

标准流转:

```text
idle -> wakeup -> listening -> recognizing -> thinking
-> replying / screening -> speaking -> idle
```

关闭 ASR、TTS 或形象渲染时，状态机降级为文本或无形象语音模式，而不是让整个大屏不可用。

## 产品成功标准

- 三块配置不同的大屏同时运行时，配置、会话、权限和监控不串屏。
- 用户不改代码即可新增大屏、替换形象、切换 Provider、发布和回滚。
- Renderer 接口支持测试形象版本切换和失败回滚；真实 2D / 3D 能力随对应 Adapter 单独验收。
- 每个外部连接都可测试、可观测、可诊断。
- 问数回答带来源、口径、参数和权限上下文。
- 非法控屏、自由 SQL、脚本、密钥暴露和跨屏越权被拒绝并审计。
- 交付包含兼容性、测试、配置快照、备份、升级和回滚证据。
