# 产品蓝图

## 产品定位

这是一个面向大屏演示场景的语音交互数字人外壳。它不强调具象人物形象, 而强调“可见、可听、可控、可解释”的交互体验:

- 可见: 语音球、声波、字幕、回复窗口、状态动效。
- 可听: ASR 输入和 TTS 播报。
- 可控: 语音指令切换 FVS 大屏页面或 Tab。
- 可解释: 会话日志、错误日志、耗时记录、演示用例。

## 第一视角体验

用户站在党建大屏前, 通过唤醒词进入对话:

```text
用户: 小天小天
系统: 进入 listening 状态, 语音球亮起
用户: 请切换到组织建设页面
系统: 识别文本, Dora 判断控屏意图, 后端校验 action_id
系统: 切换大屏, 播报“已为您切换到组织建设页面”
```

## 核心业务流程

### 1. 大屏控制

```text
语音输入
-> ASR 文本
-> Dora 识别 screen_control
-> 输出 action_id
-> Gateway 校验白名单
-> 前端 FVS Adapter 执行动作
-> TTS 播报执行结果
```

### 2. 党建知识问答

```text
语音输入
-> ASR 文本
-> Dora 选择知识库能力
-> RAGFlow 检索文档
-> Dora 生成简短回答
-> 前端展示摘要和要点
-> TTS 播报
```

### 3. 党建问数

```text
语音输入
-> ASR 文本
-> Dora Data Agent 或 Mock 数据能力
-> 返回指标值、趋势、总结
-> 前端渲染文本或 ECharts
-> TTS 播报总结
```

### 4. 领导欢迎与资料问答

```text
用户自报姓名 / 职务
-> 文本匹配领导资料
-> 唯一命中则欢迎
-> 不唯一则澄清
-> 可继续追问近期动态或资料
```

## 前端状态机

| 状态 | 含义 | 视觉表现 |
| --- | --- | --- |
| idle | 待机 | 低亮度呼吸 |
| wakeup | 识别到唤醒词 | 快速扩散光圈 |
| listening | 正在收音 | 随麦克风音量波动 |
| recognizing | 正在识别 | 字幕显示识别中 |
| thinking | Dora 正在处理 | 环形旋转 / 粒子流 |
| replying | 展示回复 | 回复窗口出现 |
| speaking | TTS 播报 | 随音频能量波动 |
| screening | 执行大屏动作 | 动作状态提示 |
| error | 异常兜底 | 红色提示后恢复 |

标准流转:

```text
idle -> wakeup -> listening -> recognizing -> thinking
-> replying / screening -> speaking -> idle
```

异常流转:

```text
任意状态 -> error -> idle
```

## 第一阶段页面布局

本地开发优先采用“数字人外壳页面嵌入 FVS”:

```text
┌────────────────────────────────────────────┐
│              FVS iframe / Mock 大屏         │
│                                            │
│     ┌──────────────────────────────┐       │
│     │       回复窗口 / 图文结果       │       │
│     └──────────────────────────────┘       │
│                                            │
│   字幕区                                   │
│                                            │
│                       语音球 / 声波 / 状态  │
└────────────────────────────────────────────┘
```

后续正式集成时, 可切换为“FVS 内嵌数字人全局浮层”。
