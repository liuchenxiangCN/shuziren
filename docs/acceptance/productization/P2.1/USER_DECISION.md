# P2.1 User Decision

## Status

- Lifecycle: `ACCEPTANCE_EVIDENCE`
- Decision: `PENDING`
- Date: `PENDING`
- Task / conversation reference: `PENDING`
- Candidate: `PENDING`

P2.1 remains active until the user explicitly records `通过`, `条件通过`,
`不通过` or `Blocked`. Completion of implementation, automated gates or
independent review is not user acceptance and does not authorize P2.2.
