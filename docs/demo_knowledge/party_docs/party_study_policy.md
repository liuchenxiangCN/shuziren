# 党员学习制度样例

## 学习目标

党员学习应围绕理论武装、党性教育、业务融合和合规意识提升开展, 服务公司党建引领业务发展的总体目标。

## 学习要求

- 每名党员应按月参加支部集中学习。
- 支部应建立学习计划、签到记录和学习台账。
- 学习内容包括党的创新理论、党内法规、公司制度和先进典型案例。
- 对未按时完成学习的党员, 支部应提醒补学并记录整改情况。

## 评价方式

党员学习完成情况可从参学次数、学习时长、测试结果和心得提交情况进行综合评价。

## 可回答问题

问: 党员学习制度有哪些要求?
答: 党员应按月参加集中学习, 支部要建立计划、签到和台账, 内容包括理论、法规、公司制度和典型案例, 未完成学习的党员需要提醒补学并记录整改。
