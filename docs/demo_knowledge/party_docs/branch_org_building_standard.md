# 党支部组织建设规范样例

## 建设目标

党支部组织建设应做到组织设置规范、职责分工明确、组织生活严肃、资料台账完整、问题整改闭环。

## 规范要求

- 支部委员会分工清晰, 责任落实到人。
- 按规定开展党员大会、支部委员会、党小组会和党课。
- 主题党日活动应有计划、有记录、有总结。
- 党员发展、组织关系转接和党费收缴应按制度执行。
- 对检查发现的问题, 应形成整改清单、责任人和完成时限。

## 展示口径

在党建大屏上, 组织建设可重点展示支部数量、组织生活完成情况、主题党日开展情况、党员发展进度和整改闭环率。

## 可回答问题

问: 党支部组织建设规范是什么?
答: 支部建设应做到组织设置规范、分工明确、组织生活按规定开展、资料台账完整、问题整改闭环。
