# V1.0 用户手册

## 适用对象

本手册面向现场演示人员和业务验收人员, 用于操作党建大屏对话数字人 POC。

## 打开系统

主页面:

```text
http://localhost:18000
```

运维页面:

```text
http://localhost:18000/ops
```

FVS 主画布模式下, 页面主体是 FVS 看板, 右下角仅显示小型语音入口。运维看板不在 FVS 主画布悬浮层中显示, 需要直接访问 `/ops`。

## 开始语音交互

1. 打开主页面。
2. 点击右下角语音入口。
3. 浏览器请求麦克风权限时选择允许。
4. 对系统说唤醒词。

支持的唤醒词:

- 小天小天
- 中天小天
- 你好小天

命中唤醒词后, 系统会立即播报:

```text
您好。
```

随后可继续说正式指令。

## 同句指令

可以把唤醒词和正式指令放在同一句中:

```text
小天小天, 当前党员学习完成率是多少?
```

期望效果:

- 系统先播报“您好。”
- 再播报“收到, 正在为您查找信息。”
- 自动识别并回答问题。

## 连续追问

系统播报回答后, 会进入短时连续追问窗口。窗口内不需要再次说唤醒词, 可以直接追问:

```text
本月主题党日开展了几次?
```

达到最大追问轮数或超时后, 系统会回到唤醒监听状态。

## 党建知识问答

示例问题:

```text
入党流程是什么?
党员学习制度有哪些要求?
党支部组织建设规范是什么?
张书记最近调研了什么?
```

期望效果:

- 返回文字摘要和要点。
- 自动 TTS 播报。
- 知识库问题由 Dora 通过 RAGFlow MCP 检索后生成回答。

## 党建问数

示例问题:

```text
当前党员学习完成率是多少?
本月有多少人完成学习?
哪个支部学习完成率最低?
本月主题党日开展了几次?
组织生活平均参会率是多少?
整改事项闭环率是多少?
当前入党积极分子有多少人?
发展对象有多少人? 分别在哪些支部?
本年转正党员有多少人?
哪些党员发展材料还待补充?
总结一下当前党建工作整体情况
```

当前默认 `ASK_METRICS_MODE=excel`, 问数来自本地脱敏 Excel 样例:

```text
docs/demo_data/ask_metrics/
```

回答会显示数据来源, 例如:

```text
zt_party_study_metrics_2026.xlsx / Dashboard
```

注意: 当前问数数据是 POC 脱敏样例, 不代表客户真实生产数据。

## 大屏切换

示例指令:

```text
返回总览
切换到成品库存
打开生产管理
切换到设备分析
```

当前 FVS 测试看板映射:

| 说法 | action_id | FVS page_number |
| --- | --- | --- |
| 返回总览 | `SWITCH_HOME` | 1 |
| 切换到成品库存 | `SWITCH_TAB_ORG` | 2 |
| 打开生产管理 | `SWITCH_TAB_STUDY` | 3 |
| 切换到设备分析 | `SWITCH_TAB_ACTIVITY` | 4 |

系统只会执行后端白名单允许的 `action_id`。不在白名单中的页面不会被切换。

## 播报和字幕

系统会优先使用 TTS 字节级真流式播放回答。若真流式失败, 会回退到分段 TTS; 若分段 TTS 也不可用, 仍保留文字回答。

正式指令进入处理后, 系统会播放等待提示:

```text
收到, 正在为您查找信息。
```

AI 最终回答音频到达后, 会打断等待提示并优先播放最终回答。

## 兜底提示

常见兜底:

| 场景 | 系统表现 |
| --- | --- |
| 未命中唤醒词 | 不展开对话层, 不进入正式对话 |
| Dora 暂不可用 | 返回安全兜底话术; 演示稳态可回退本地演示规则 |
| 问数数据缺失 | 提示问数数据不可用 |
| TTS 失败 | 保留文字回答, 不暴露供应商异常 |
| 麦克风权限被拒绝 | 前端提示检查浏览器权限和设备 |
| FVS iframe 加载失败 | 前端显示 FVS 看板暂不可用 |
| 非法页面切换 | 不执行动作, 返回当前大屏暂不支持 |

## 演示稳态标识

如果以以下命令启动:

```powershell
scripts\start-poc.ps1 -Build -DemoStable
```

前端会显示“演示稳态”。该模式只用于降低外部 Dora 临时不可用对固定演示的影响, 不能替代真实依赖验收。

## 使用注意

- 请在安静环境中演示语音唤醒。
- 浏览器麦克风权限必须允许。
- 演示前确认系统音量和音箱可用。
- 不要在前端或运维页面输入 API Key。
- 不要要求系统执行未配置白名单的大屏动作。
- 若需查看运行状态, 访问 `/ops`。
