# ADR-0001 Project Scope

## Status

Superseded by ADR-0026

## Superseded

2026-07-26 起，ADR-0026 定义标准产品目标并纳入 2D / 3D 形象、多大屏控制面和产品级交付。本 ADR 继续记录 POC 阶段的历史边界，不再限制产品化 P3 范围。

## Context

客户已有 Dora 平台和 FVS 大屏看板。本阶段目标是在本地 Windows + Docker 环境补齐数字人交互组件, 跑通 POC 主链路, 而不是重新开发大屏或一次性完成生产级系统。

## Decision

本阶段定位为本地 POC 工程:

- 不做 2D / 3D 数字人形象。
- 不做声纹、人脸、系统级常驻唤醒。
- 不重新开发 FVS 大屏内容。
- 不做正式生产知识库调优。
- 优先跑通端到端链路。
- 文档和配置按可复用客户模板设计。

## Consequences

优点:

- 开发边界清晰。
- 可快速形成演示闭环。
- 后续可迁移给其他客户复用。

代价:

- 第一阶段效果不等于生产效果。
- 部分外部系统能力需要后续联调确认。
- POC 前仍需补齐合规、网络、安全和运维方案。
